# StrideFlow – Interactive Shoe Showcase
This Figma project is a dynamic shoe advertisement design featuring three different shoes displayed in an interactive layout. One shoe is shown prominently at a time, accompanied by product information on the side. Users can navigate through the collection using next and previous buttons, smoothly transitioning between shoes. With each change, the background gradient dynamically adjusts to match the colors of the selected shoe, creating a visually cohesive experience. The design emphasizes smooth motion, modern aesthetics, and a seamless product storytelling flow.
